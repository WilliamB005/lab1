# TaskFlow - Responsive Landing Page

A mobile-first, responsive landing page built for TaskFlow. This project demonstrates modern layout techniques using CSS Grid for page structure and Flexbox for section content.

---

## 🚀 Features & Technical Highlights

* **Mobile-First Architecture:** Base styles target small screens, adapting smoothly up to desktop widths (1440px) without horizontal scrolling.
* **CSS Grid Layout:** Powers the overall page structure (`.page-grid`) and main content layout (`.main-content-grid`).
* **Flexbox Elements:** Manages UI components such as header navigation, feature card rows, and footer links.
* **Design System:** Standardized typography, unified color palette, and spacing scale built with CSS custom variables (`:root`).
